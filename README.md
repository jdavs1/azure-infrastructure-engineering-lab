Azure Infrastructure Engineering Lab

Welcome to my Azure Infrastructure Engineering Lab. This project was built to simulate a real-world Azure environment using Infrastructure as Code with Bicep.

The goal of this lab was to design, deploy, secure, monitor, and protect a multi-resource Azure environment while applying practical cloud engineering and security concepts. The environment includes segmented networking, Linux virtual machines, private storage access, managed identities, RBAC, Azure Monitor, alerting, and backup protection.

Rather than building everything manually in the Azure portal, the final environment is fully defined through modular Bicep templates so the infrastructure can be deployed consistently and recreated when needed.

This project demonstrates hands-on experience with:

Azure Virtual Networks and subnet segmentation
Network Security Groups
Linux virtual machines
SSH-based administration
Azure Managed Identities
Role-Based Access Control
Azure Blob Storage
Private Endpoints and Private DNS
Azure Monitor and Log Analytics
Data Collection Rules
Metric alerts and Action Groups
Recovery Services Vault and VM backup
Modular Infrastructure as Code with Bicep

The project was designed as a learning environment, but the architecture and deployment workflow are intended to reflect practices commonly used in real Azure environments.
